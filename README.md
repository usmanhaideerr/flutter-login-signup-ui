# Flutter Auth UI

A clean, modern, and responsive **Login & Signup UI** built with Flutter. This project focuses on the front-end design of authentication screens and can be easily connected to any backend (Firebase, REST API, Supabase, etc.).


## Features

- Beautiful Login screen
- Signup screen with form fields
- Form validation (email, password, etc.)
- Password show/hide toggle
- Responsive layout for different screen sizes
- Clean, reusable widgets
- Easy to customize colors and styles

## Getting Started

### Prerequisites

- [Flutter SDK](https://docs.flutter.dev/get-started/install) (3.x or later)
- Dart SDK
- Android Studio / VS Code
- An emulator or physical device

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/flutter-auth-ui.git
   ```

2. **Go to the project folder**
   ```bash
   cd flutter-auth-ui
   ```

3. **Install dependencies**
   ```bash
   flutter pub get
   ```

4. **Run the app**
   ```bash
   flutter run
   ```
